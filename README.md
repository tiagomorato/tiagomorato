# Hi, I'm Tiago 👋

I build test automation and CI quality gates. I spent three years as a working-student software tester at **Hacon** (a Siemens company), testing the system Deutsche Bahn uses to register track work. There I automated critical and regression tests with **Selenium (Python)** and **Cypress (TypeScript)**.

I'm finishing an **M.Sc. in Applied Computer Science** at Universität Hildesheim (03/2027), focused on software engineering, testing and NLP. Alongside it I work as a research assistant, fine-tuning BERT for text classification on the university GPU cluster.

🎯 **Looking for:** Full time IT roles in Germany from **04/2027**

## Highlighted projects

### [Qwixx Scoreboard](https://github.com/tiagomorato/qwixx)

A live-synced scoreboard web app for the Qwixx dice game (TypeScript, Bun, React, Server-Sent Events). Built spec-first with GitHub Spec Kit and Claude Code, and tested in four layers: 78 unit tests, performance budgets, and 17 Playwright end-to-end tests with axe-core accessibility audits, all gated in CI. Making the E2E suite reliable also turned up a real cross-device sync bug, which is now fixed.

### University portal automations

A suite of three small, fully tested Python automations:
